
## Elementor (Page Builder)

#  Task 1: Implement Core Concept – Elementor

Elementor is a drag-and-drop page builder plugin in WordPress used to design web pages without coding.
 Responsive design,Pre-built templates and widgets  


# Task 2: Create / Configure Features

##  Install Elementor
1. Go to Dashboard → Plugins → Add New  
2. Search: Elementor  
3. Click Install → Activate  

<img width="1918" height="885" alt="image" src="https://github.com/user-attachments/assets/6dd618e0-fa08-4747-9a94-62602da5e654" />



## Create Page Using Elementor
1. Go to Pages → Add New  
2. Click **Edit with Elementor**  
3. Drag widgets like:
   - Heading, Image,Button



## 🎯 Add Features
- Hero section (title) 
- About section
