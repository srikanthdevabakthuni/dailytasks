# Day 10 — Business Website using Envo Storefront  


##  Task 1  

### Initial Setup & Theme Understanding  

Gained understanding of building a business/eCommerce website using the Envo Storefront theme in WordPress.

**Activities performed:**
  
- Installed and activated Envo Storefront theme
- Imported demo data
- Explored default layout and theme structure  
- Checked WooCommerce compatibility  


##  Task 2  

### WooCommerce Setup & Demo Configuration  

Configured the website with eCommerce functionality and demo content.

**Activities performed:**

- Installed and activated WooCommerce  
- Completed setup wizard  
- Installed Elementor and demo importer  
- Imported demo site  
- Fixed demo import issues  
- Verified homepage sections (banners, categories, products)  


## Task 3  

### Page Creation & Homepage Design  

Customized website structure and homepage.

**Activities performed:**

- Created pages: Home, Shop, About, Contact  
- Set static homepage  
- Edited homepage using Elementor  
- Updated banners and product sections  
- Added sample products  


##  Task 4  

### Debugging & Optimization  

Improved performance and fixed issues.

**Activities performed:**

- Fixed layout alignment issues  
- Checked product display    
- Verified responsiveness  

## 🔹 Task 5  

### Documentation & Final Output  

Verified complete website setup.

**Final Output:**

- Envo Storefront theme installed  
- WooCommerce working properly  
- Homepage customized  
- Navigation working smoothly  
- Mobile responsive design    
- Website ready for use
